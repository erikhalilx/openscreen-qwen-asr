# OpenScreen Qwen v0.3.0 功能说明书

## 运行要求

- Qwen 本地转录需要 Apple Silicon Mac 和 macOS 26 或更新版本；Windows、Linux 和 Intel Mac 不支持本版本的 Qwen 推理。
- 首次安装运行环境和模型需要联网，并建议预留至少 8 GB 可用空间；安装完成后转录可离线运行。
- 录屏、编辑器、时间线和导出仍保留 OpenScreen 的多平台代码，但 Qwen 运行能力只支持上述 macOS 环境。
- v0.3.0 是源码预览版本，GitHub 发布页不附带 DMG 安装包。

## 功能概览

### 本地 Qwen3-ASR 转录

应用使用本地 Qwen3-ASR-0.6B、Qwen3-ForcedAligner-0.6B 和 Silero VAD 完成识别及字级/词级时间戳。支持中文、英语、粤语、法语、德语、意大利语、日语、韩语、葡萄牙语、俄语和西班牙语；其他语言会明确报错。音频不会上传到转录服务，识别结果仍需人工校对。

### 缺少组件时补装

在“工作室 → 转录文本”面板中，缺少运行组件时点击“保存补装脚本”，保存 `Install OpenScreen Qwen.command` 并双击运行。脚本会安装锁定版本的 Python 3.12 环境、依赖、模型和 VAD，完成后按 ⌘Q 完全退出应用并重新打开。运行时和配置保存在：

```text
~/Library/Application Support/OpenScreen-Qwen/
```

该按钮只保存脚本，不代表安装已经完成；组件就绪后入口会隐藏。应用不会因为空间不足自动阻止安装，请按要求预留磁盘空间。

### 独立系统声与麦克风音轨

录制时可分别启用系统声和麦克风，并为每一路设置 0–200% 的录制音量。录制后两路声音保留为独立音轨，可在“音频”面板分别调节增益和静音，并跟随共用画面时间线剪切、移动和变速。录制音量为 0% 会产生不可恢复的静音。移动项目时应同时保留 `.mp4`、`.session.json`、`-system.m4a` 和 `-microphone.m4a` 等关联文件；旧版混音录音不能事后拆分。

### 双来源转录、字幕与 SRT

系统声和麦克风可以分别转录、校对、点击定位和按文字剪辑；文字修改只影响当前来源，语音剪辑会影响共用画面时间线及两路音频。音频静音和字幕显示相互独立。

“字幕”面板可以分别启用两路字幕，并为每一路设置字体、颜色、底板、位置、边距、行长和翻译。双轨同时显示时会自动分层，默认系统声字幕更靠近画面中心；“调换两轨字幕位置”只交换显示高度，不交换文字或样式。字幕每条最多额外显示 1 秒实际播放时间，遇到同源下一句或视频结束会提前停止；行长范围为 1–25 个对齐单元。

在“转录文本”工具行或“字幕”标题栏点击“SRT”，选择系统音频或麦克风即可分别导出 UTF-8 SRT。导出使用当前文字、行长、翻译以及剪切/变速后的成片时间轴，即使该来源字幕隐藏也可以导出；SRT 不包含字体、颜色和位置样式。

### 鼠标音效试听

工作室“音频”面板提供“写实”和“气泡”两种鼠标音效风格。点击按钮会试听一次对应的单击样本，重复点击当前风格也会重新试听。试听不会自动启用成片鼠标声音；要写入视频，仍需启用“鼠标声音”并调整项目点击音量。

### 摄像头布局与录制权限

摄像头布局支持画中画、并排、上下排列、仅摄像头和仅屏幕，并可在布局面板或时间线布局段中逐段设置屏幕/摄像头圆角等参数。没有可用摄像头的时间段不能选择需要摄像头的布局。“仅屏幕”始终可用。

macOS 会在倒计时前准备录制所需的屏幕录制、辅助功能和麦克风权限；仍需按系统提示完成授权，本功能不绕过系统权限。

## 数据与隐私

Qwen 运行环境、模型和私有配置与应用及源码目录分离。应用不启用上游使用量统计遥测和自动更新；首次安装会访问模型清单中的下载主机，之后本地转录不需要联网。AI 对话、翻译和 MCP 服务仍按用户自己的配置启用。

## 常用流程

1. 录制界面中选择屏幕或窗口，按需启用系统声和麦克风并确认录制音量不为 0%。
2. 录制一段短素材并在工作室中分别转录、校对两路音频。
3. 在“字幕”面板分别启用来源、调整样式和双轨位置。
4. 在“转录文本”或“字幕”中分别导出系统声和麦克风 SRT，然后按原流程预览和导出视频。
5. 保存工程文件及其所有关联媒体素材。

## 旧项目兼容

Studio 0.3 使用 `studioVersion === 3` 标记识别新项目。旧项目打开时会依据原始素材重建时间线：项目身份、素材记录和路径保留，但原剪辑、转录、字幕、布局、效果、缩放及独立音轨编排不会自动恢复。分离的系统声和麦克风会按新时间线重建，增益恢复为 0 dB、静音关闭。打开旧项目前请先复制工程及关联素材，并使用副本测试；首次保存后重建状态会被持久化。
